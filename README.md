# 🤖 AI Interview Preparation Platform (Frontend)

An AI-powered interview preparation platform that helps users prepare for technical and HR interviews through personalised learning, AI-powered resume analysis, and mock interviews.

## 🚀 Features

- User Authentication (Login & Registration)
- AI Resume Analyzer
- AI Mock Interview
- Java Interview Questions
- DSA Practice
- Progress Dashboard
- Responsive UI

## 🛠️ Tech Stack

- React.js
- React Router
- Axios
- CSS
- Framer Motion

## 📁 Project Structure

```
src/
├── components/
├── pages/
├── services/
├── assets/
└── App.js
```

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Vaishnavi174/AI_Interview_prep.git
```

2. Install dependencies

```bash
npm install
```

3. Start the application

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
